Tidak Follow Balik
1

Buka Instagram

Buka aplikasi Instagram → Profil → Menu (tiga garis) → Pengaturan dan privasi

2

Pusat Akun → Informasi Anda

Scroll ke bawah → ketuk Pusat Akun → pilih Informasi Anda di Meta → Unduh informasi Anda

3

Pilih format HTML

Pada halaman unduh, pilih akun Instagram kamu, set format ke HTML, rentang tanggal Sepanjang Masa, lalu ketuk Buat File

4

Unduh & Ekstrak

Instagram akan mengirim email berisi link unduhan. Unduh file ZIP, lalu ekstrak. Buka folder followers_and_following/

5

Upload ke sini

Upload file followers_1.html dan following.html ke kotak di atas, lalu klik Analisis Sekarang

Semua file diproses sepenuhnya di browser kamu. Tidak ada data yang dikirim atau disimpan di server manapun.
